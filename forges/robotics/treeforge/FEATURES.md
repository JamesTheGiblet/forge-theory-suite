# ✨ Features

The Organic Tree Growth Simulator provides a rich set of features for generating and interacting with procedural trees.

## 🌳 Tree Customization

- **Tree Type Presets:** Quickly switch between different tree archetypes with distinct characteristics:
  - Oak
  - Pine
  - Willow
- **Show/Hide Leaves:** Toggle the visibility of leaves for a different aesthetic or to focus on the branch structure.

## 🧬 Evolution Parameters

Fine-tune the core recursive algorithm of the tree's structure.

- **Branch Angle:** Control the angle of divergence for new branches.
- **Branch Length Ratio:** Set how much shorter each new branch generation is compared to its parent.
- **Thickness Decay:** Determine how quickly branches get thinner as they grow.
- **Max Depth:** Set the maximum number of recursive iterations, controlling the tree's complexity.

## 🌬️ Growth Dynamics

Introduce organic and natural-looking variations to the tree.

- **Randomness:** Add random variations to branch angles for a less uniform look.
- **Asymmetry:** Introduce a bias to make branches favor growing more to one side.
- **Gravity Influence:** Simulate the effect of gravity, causing branches to droop as they extend.

## 🎬 Time-Lapse & Animation

- **Play/Pause/Reset:** Control the animated growth of the tree from a seed to its full form.
- **Growth Stage Slider:** Manually scrub through the tree's entire life cycle.
- **Animation Speed:** Control the speed of the growth animation.

## 💾 Export Options

- **Export to SVG:** Save your current tree as a resolution-independent SVG file, perfect for use in other design tools.
- **Export to Code:** Generate a self-contained JavaScript code snippet that can reproduce the current tree with its exact parameters.
