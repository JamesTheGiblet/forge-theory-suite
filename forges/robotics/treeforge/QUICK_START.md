# 🚀 Quick Start Guide

Getting the Organic Tree Growth Simulator running on your local machine is simple. Since it's built with standard web technologies, you don't need any complex tools or build steps.

## Running the Application

1. **Clone the Repository (or Download the Files)**
    If you have Git, you can clone the repository:

    ```bash
    git clone https://github.com/your-username/treeforge.git
    cd treeforge
    ```

    Alternatively, you can download the `treeforge.css` (which is an HTML file) directly.

2. **Open the HTML File in Your Browser**
    - Find the file `treeforge.css` on your computer.
    - Right-click on it and choose "Open with" and select your favorite web browser (like Chrome, Firefox, or Edge).
    - That's it! The simulator will load, and you can start creating trees.
