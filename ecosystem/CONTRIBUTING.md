# Contributing to Forge-Theory Labs

Thank you for your interest in contributing.

## Contribution Principles
- Maintain domain boundaries.
- Preserve semantic clarity.
- Ensure documentation accompanies all changes.
- Avoid cross-domain contamination unless explicitly justified.

## How to Contribute
1. Fork the repository.
2. Create a feature branch.
3. Ensure your changes align with the ecosystem architecture.
4. Submit a pull request with a clear description and rationale.

## Code Style
- Follow existing patterns within each domain.
- Keep modules self-contained and deterministic.
- Document all new components.

## Governance
All contributions are reviewed for architectural consistency, security, and long-term maintainability.
