## Platform Overview

The CCE Unreal Platform is a complete ecosystem for building, validating, and deploying algorithmic trading strategies. It has five layers:

**Layer 1 — Framework SDK**
Standardised engine contract with lifecycle management, circuit breakers, dry-run enforcement, and sql.js storage. Every engine speaks the same language. The registry auto-detects and loads engines from the `engines/` folder on boot — no hardcoding required.

**Layer 2 — Visual Engine Builder**
A touch-optimised node-based FSM editor that runs in any browser. Tap state types to add nodes. Connect ports to draw transitions. Configure conditions and allocations in a bottom sheet. Hit FORGE to generate valid engine code.

**Layer 3 — Backtest Replay**
A timeline player for backtest runs. Watch your engine trade through 10 years of history frame by frame. State colour bands, live signals panel, portfolio bar, transition log, and scrub controls.

**Layer 4 — Cloud Deploy CLI**
One command from phone to VPS. `cce-deploy push se-forex` validates, backs up, rsyncs, restarts PM2, and verifies — all in under 60 seconds. Rollback restores the previous version instantly.

**Layer 5 — Marketplace**
Pipeline-signed listings. Every engine comes with a metrics card generated by the pipeline — not the seller. OOS CAGR, Sharpe, MaxDD, OOS/IS ratio, walk-forward consistency, stress tests. The proof, not the pitch.

## The Pipeline Trust Model

Every engine on the marketplace passes through the CCE AI Framework Pipeline:

```
STEP 1  Target Definition    — hypothesis locked, success criteria set
STEP 2  Data Gathering       — 10yr price, sentiment, dominance, lag analysis
STEP 3  State Analysis       — full cycles identified, temporal lags measured
STEP 4  Strategy Generation  — FSM generated from state map
STEP 5  Backtest & Signoff   — IS/OOS split, walk-forward, stress tests, signed card
```

The metrics card is **signed by the pipeline** — not the seller. Buyers see the same data the builder saw.

## Quick Start

```bash
# Scaffold a new engine
cce new-engine my-engine --type strategic --cycle 4H

# Validate it
cce validate my-engine

# See it in the registry (after pm2 restart)
cce list

# Deploy to VPS
cce-deploy push my-engine
```
