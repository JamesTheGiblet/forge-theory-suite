# SHA-256 Computation Example
# Demonstrates the canonical hash algorithm from UBVM-SPEC-001 §9.1

INPUT: canonical JSON of chain_root_capsule.json (see canonical_json_example.txt)

ALGORITHM:
  1. Take capsule JSON object
  2. Remove provenance.sha256 field
  3. Remove metadata field (if present)
  4. Sort all keys lexicographically (recursive)
  5. Serialise to compact JSON (no whitespace) with UTF-8 encoding
  6. Compute SHA-256 of byte string
  7. Encode result as lowercase hexadecimal

RESULT:
  35fbfe42a8188d0f0197d4ee33822a9ebcde78abbf82fcb028b575dc43c30df8

VERIFICATION:
  node -e "const {canonicalHash}=require("./02_REFERENCE_IMPLEMENTATION/ubvm.js"); const c=require("./06_ARTIFACTS/hash_chains/chain_root_capsule.json"); console.log(canonicalHash(c) === c.provenance.sha256 ? "MATCH" : "MISMATCH")"

Expected output: MATCH
