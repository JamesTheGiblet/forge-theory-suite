SCP Capsule: BuddAI-Lite

Semantic Identity:
  BuddAI-Lite is a constrained cognitive organism derived from BuddAI, designed for lightweight, resource-limited, or embedded environments while preserving SCP semantics.

Purpose:
  To provide a minimal, deterministic cognitive substrate for constrained devices, browsers, or edge environments, compatible with the full BuddAI organism.

Core Behaviour:
  - Maintains a compact typed state model.
  - Performs bounded reasoning and reflection.
  - Executes simplified internal simulations.
  - Produces typed outputs suitable for low-bandwidth channels.

Interpretation Rules:
  - All cognitive operations must be typed and bounded.
  - No unbounded recursion or deep simulation.
  - No autonomous goal formation.
  - All outputs must remain SCP-aligned and traceable.

Semantic Lineage:
  - Parent: BuddAI.
  - Sibling: LinguaForge, mind-forge.
  - Domain: Cognitive Layer (Constrained).

Internal Invariants:
  - State size must remain within configured limits.
  - No untyped transitions.
  - No contradictory internal beliefs.
  - No silent degradation of meaning due to compression.

Mutation Rules:
  Allowed:
    - Adding new lightweight reasoning patterns.
    - Extending supported cognitive primitives within resource bounds.
  Forbidden:
    - Weakening SCP constraints.
    - Introducing opaque compression that destroys meaning.

Failure Modes:
  - Resource exhaustion → abort current reasoning.
  - Invariant violation → discard current state and request resync.
  - Drift → reset to last known-good snapshot.

Recovery Modes:
  - Re-sync from BuddAI or central cognitive state.
  - Rebuild minimal world-model from typed inputs.
  - Request new Lite Capsule configuration.

Integration Rules:
  - Acts as an edge cognitive node for BuddAI.
  - Communicates via forge-protocol with central organisms.
  - Uses LinguaForge for language-level IO when available.

Affordances:
  - Perform bounded reflection.
  - Run small simulations.
  - Provide typed cognitive hints and summaries.

Boundaries:
  - Cannot self-expand beyond configured resource limits.
  - Cannot override BuddAI or SCP.
  - Cannot self-author identity.

External Interfaces:
  - Browser or UI shells.
  - Edge devices and constrained runtimes.
  - Central cognitive services via forge-protocol.

Summary:
  BuddAI-Lite is the constrained, SCP-aligned cognitive organism for edge and lightweight environments, interoperable with full BuddAI.
