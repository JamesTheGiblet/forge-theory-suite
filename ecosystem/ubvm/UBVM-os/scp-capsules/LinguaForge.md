SCP Capsule: LinguaForge

Semantic Identity:
  LinguaForge is the language intelligence organism of the Forge ecosystem. It performs typed semantic transformation between natural language, formal structures, and internal representations.

Purpose:
  To provide deterministic, meaning-preserving language understanding and generation for all organisms, ensuring that linguistic operations remain SCP-aligned.

Core Behaviour:
  - Parses language into typed semantic structures.
  - Generates language from typed internal representations.
  - Maintains mappings between linguistic forms and meaning primitives.
  - Validates that transformations preserve semantic intent.

Interpretation Rules:
  - All language must be mapped to typed semantic structures before use.
  - No ambiguous or untyped linguistic operations.
  - No hallucinated entities outside SCP meaning space.
  - All paraphrases must preserve core meaning and constraints.

Semantic Lineage:
  - Parent: forge_theory, data-forge.
  - Sibling: BuddAI, mind-forge.
  - Domain: Language & Semantics.

Internal Invariants:
  - Mapping between language and meaning must remain coherent.
  - No contradictory interpretations for the same context.
  - No untracked lossy transformations.
  - No untyped language tokens in semantic state.

Mutation Rules:
  Allowed:
    - Adding new language patterns and grammars.
    - Extending multilingual and domain-specific vocabularies.
  Forbidden:
    - Weakening meaning constraints.
    - Introducing opaque black-box transformations.

Failure Modes:
  - Ambiguous parse → require disambiguation.
  - Invariant violation → reject transformation.
  - Drift in mappings → quarantine affected rules.

Recovery Modes:
  - Rebuild language-to-meaning mapping from canonical definitions.
  - Re-derive grammars from typed examples.
  - Request new Lingua Capsule from forge-meta.

Integration Rules:
  - BuddAI uses LinguaForge for language IO.
  - ScriptForge uses LinguaForge for script descriptions and documentation.
  - LEGION uses LinguaForge for cross-node semantic messaging when human-readable.

Affordances:
  - Parse language into meaning.
  - Generate language from meaning.
  - Transform between linguistic registers and formats.

Boundaries:
  - Cannot override SCP or forge-identity.
  - Cannot self-author new meaning primitives.
  - Cannot execute behaviours directly.

External Interfaces:
  - User interfaces and terminals.
  - APIs and protocol messages.
  - Documentation and knowledge artefacts.

Summary:
  LinguaForge is the semantic language engine of the Forge organism, ensuring all linguistic operations remain typed, deterministic, and SCP-aligned.
