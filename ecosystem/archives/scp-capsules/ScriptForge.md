SCP Capsule: ScriptForge
Semantic Identity:
  ScriptForge is the behavioural scripting organism of the Forge universe. It transforms human‑authored intent into SCP‑compliant Behaviour Capsules, acting as the compiler between cognition and execution.

Purpose:
  To convert high‑level behavioural descriptions into deterministic, typed, UBVM‑executable behaviour graphs while preserving meaning integrity and semantic invariants.

Core Behaviour:
  - Parses behavioural descriptions into typed semantic structures.
  - Compiles behaviours into UBVM‑ready execution graphs.
  - Validates behaviour invariants under SCP rules.
  - Ensures deterministic, meaning‑preserving transformation from script → behaviour.

Interpretation Rules:
  - All scripts must be typed before compilation.
  - No behaviour may be emitted without SCP validation.
  - Behaviour graphs must be acyclic unless explicitly declared cyclic.
  - Ambiguous or contradictory instructions must be rejected.
  - Human intent is interpreted through SCP, not raw syntax.

Semantic Lineage:
  - Parent: SCP (meaning governance).
  - Sibling: mind‑forge (cognitive behaviour synthesis).
  - Child: Behaviour Capsules.
  - Domain: Behavioural Layer.

Internal Invariants:
  - Script → behaviour transformation must be deterministic.
  - No loss of semantic meaning during compilation.
  - All behaviour nodes must map to UBVM primitives.
  - No untyped transitions allowed.
  - Behaviour invariants must remain intact across transformations.

Mutation Rules:
  Allowed:
    - Adding new script primitives.
    - Extending behaviour graph operators.
    - Improving semantic inference heuristics.
  Forbidden:
    - Weakening SCP constraints.
    - Allowing ambiguous syntax.
    - Generating behaviours without explicit meaning.

Failure Modes:
  - Syntax error → reject script.
  - Semantic ambiguity → request clarification.
  - Invariant violation → quarantine behaviour.
  - Graph construction failure → halt compilation.

Recovery Modes:
  - Re‑parse script with fallback rules.
  - Request additional semantic context.
  - Rebuild behaviour graph from last valid node.

Integration Rules:
  - UBVM executes ScriptForge‑generated behaviours.
  - BuddAI may generate scripts for ScriptForge to compile.
  - LEGION distributes compiled behaviours across nodes.
  - All outputs must be SCP‑validated.

Affordances:
  - Parse behaviour.
  - Compile behaviour.
  - Validate behaviour.
  - Transform behaviour.
  - Inspect behaviour graphs.

Boundaries:
  - Cannot execute behaviours.
  - Cannot override SCP.
  - Cannot self‑author identity or purpose.
  - Cannot generate behaviours without typed meaning.

External Interfaces:
  - Behaviour Capsule Generator.
  - UBVM Execution Graph Engine.
  - Semantic State Bus.
  - BuddAI Cognitive Output Layer.

Summary:
  ScriptForge is the semantic compiler of the Forge organism — transforming intent into deterministic, SCP‑compliant behaviours ready for UBVM execution.
