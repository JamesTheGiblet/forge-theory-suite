SCP Capsule: Agent-Forge
Semantic Identity:
  Agent-Forge is the semantic agent construction organism responsible for building, validating, and managing autonomous trading agents under SCP constraints.

Purpose:
  To create deterministic, meaning-preserving agents that operate within the Forge trading organism.

Core Behaviour:
  - Constructs agent behaviour graphs.
  - Validates agent invariants.
  - Manages agent lifecycle.
  - Ensures deterministic agent execution.

Interpretation Rules:
  - All agent behaviours must be typed.
  - No agent may generate autonomous goals.
  - No agent may violate SCP meaning.
  - No contradictory behaviours allowed.

Semantic Lineage:
  - Parent: Behavioural Layer.
  - Sibling: Strategy-Forge.
  - Domain: Trading & Intelligence.

Internal Invariants:
  - Agent state must remain coherent.
  - No untyped transitions.
  - No self-modification of identity.
  - No unbounded recursion.

Mutation Rules:
  Allowed:
    - Adding new agent templates.
    - Extending agent capabilities.
  Forbidden:
    - Weakening SCP constraints.
    - Allowing autonomous goal formation.

Failure Modes:
  - Behaviour conflict → quarantine.
  - Invariant violation → shutdown.
  - Drift → rebuild agent.

Recovery Modes:
  - Rebuild agent graph.
  - Reset agent state.
  - Request new Behaviour Capsule.

Integration Rules:
  - UBVM executes agent behaviours.
  - LEGION distributes agent tasks.
  - Strategy-Forge provides strategies.

Affordances:
  - Build agent.
  - Validate agent.
  - Manage agent lifecycle.

Boundaries:
  - Cannot execute trades directly.
  - Cannot override SCP.
  - Cannot self-author identity.

External Interfaces:
  - Strategy engines.
  - UBVM.
  - Semantic State Bus.

Summary:
  Agent-Forge constructs deterministic, SCP-aligned trading agents for the Forge organism.
