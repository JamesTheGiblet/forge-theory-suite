SCP Capsule: mind-forge
Semantic Identity:
  mind-forge is the cognitive behaviour synthesis organism. It generates new behaviours through reflective reasoning, semantic inference, and meaning‑preserving transformation of cognitive structures.

Purpose:
  To create high‑level behavioural strategies, plans, and cognitive actions that ScriptForge compiles and UBVM executes. mind‑forge is the bridge between cognition and behaviour.

Core Behaviour:
  - Synthesises behaviours from cognitive graphs.
  - Performs reflective loops to refine behavioural intent.
  - Generates structured behavioural plans.
  - Ensures all behaviours align with SCP meaning.

Interpretation Rules:
  - All cognitive inputs must be typed.
  - No behaviour may be generated without explicit semantic grounding.
  - Reflective loops must converge toward clarity.
  - Behavioural synthesis must preserve invariants.
  - No autonomous goal generation allowed.

Semantic Lineage:
  - Parent: BuddAI (cognitive organism).
  - Sibling: ScriptForge (behaviour compiler).
  - Child: High‑level Behaviour Capsules.
  - Domain: Behavioural Layer.

Internal Invariants:
  - Cognitive graph must remain coherent.
  - No contradictory behavioural goals allowed.
  - Behavioural synthesis must remain deterministic.
  - No untyped cognitive transitions.
  - Reflective loops must not diverge.

Mutation Rules:
  Allowed:
    - Adding new cognitive operators.
    - Extending behavioural inference rules.
    - Improving reflective loop heuristics.
  Forbidden:
    - Altering identity or purpose.
    - Generating autonomous goals.
    - Weakening SCP meaning constraints.

Failure Modes:
  - Cognitive ambiguity → request clarification.
  - Behavioural conflict → quarantine behaviour.
  - Reflective loop divergence → halt synthesis.
  - Invariant violation → reject behaviour.

Recovery Modes:
  - Rebuild cognitive graph.
  - Re‑evaluate user intent.
  - Reconstruct behavioural plan.
  - Request new semantic context.

Integration Rules:
  - ScriptForge compiles mind‑forge behaviours.
  - UBVM executes compiled behaviours.
  - LEGION distributes cognitive tasks.
  - BuddAI supervises cognitive synthesis.

Affordances:
  - Generate behaviour.
  - Refine behaviour.
  - Reflect on behaviour.
  - Transform cognitive structures.
  - Produce behavioural plans.

Boundaries:
  - Cannot execute behaviours.
  - Cannot override SCP.
  - Cannot self‑modify identity.
  - Cannot generate goals without user intent.

External Interfaces:
  - BuddAI Cognitive Graph Engine.
  - ScriptForge Compiler.
  - Semantic State Bus.
  - Behaviour Capsule Generator.

Summary:
  mind‑forge is the cognitive behaviour generator of the Forge organism — transforming thought into structured, SCP‑aligned behavioural intent.
