SCP Capsule: logic-forge
Semantic Identity:
  logic-forge is the semantic logic organism. It defines typed logical structures, inference rules, and reasoning primitives for the Forge universe.

Purpose:
  To provide deterministic, meaning-preserving logical reasoning for cognition, behaviour, intelligence, and semantic validation.

Core Behaviour:
  - Defines typed logical operators.
  - Validates logical consistency.
  - Provides inference primitives.
  - Ensures deterministic reasoning.

Interpretation Rules:
  - All logic must be typed.
  - No contradictory propositions allowed.
  - No unbounded inference.
  - All reasoning must preserve SCP meaning.

Semantic Lineage:
  - Parent: forge_theory.
  - Sibling: math-forge, data-forge.
  - Domain: Domain Forges.

Internal Invariants:
  - Logical structures must remain coherent.
  - No untyped transitions.
  - No contradictory inference chains.
  - No weakening of logical axioms.

Mutation Rules:
  Allowed:
    - Adding new logical operators.
    - Extending inference rules.
  Forbidden:
    - Allowing contradictions.
    - Weakening SCP meaning constraints.

Failure Modes:
  - Contradiction → quarantine.
  - Invariant violation → reject.
  - Divergence → halt.

Recovery Modes:
  - Rebuild logical graph.
  - Re-evaluate premises.
  - Request new Logic Capsule.

Integration Rules:
  - BuddAI uses logic-forge for reasoning.
  - ScriptForge uses logic-forge for validation.
  - LEGION uses logic-forge for distributed truth.

Affordances:
  - Infer.
  - Validate.
  - Transform logic.

Boundaries:
  - Cannot override SCP.
  - Cannot self-author identity.

External Interfaces:
  - Cognitive systems.
  - Behavioural systems.

Summary:
  logic-forge provides the logical backbone for all reasoning in the Forge organism.
