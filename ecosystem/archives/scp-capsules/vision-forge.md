SCP Capsule: vision-forge
Semantic Identity:
  vision-forge is the semantic vision organism. It defines typed visual structures, perception primitives, and meaning-preserving transformations for visual data.

Purpose:
  To provide deterministic, SCP-compliant visual perception for robotics, cognition, intelligence, and behaviour.

Core Behaviour:
  - Types visual input.
  - Extracts semantic features.
  - Maintains coherent visual state.
  - Publishes typed perception capsules.

Interpretation Rules:
  - All visual data must be typed.
  - No ambiguous perception allowed.
  - No contradictory visual state.
  - All transformations must preserve meaning.

Semantic Lineage:
  - Parent: data-forge.
  - Sibling: audio-forge.
  - Domain: Domain Forges.

Internal Invariants:
  - Visual state must remain coherent.
  - No untyped transitions.
  - No contradictory features.
  - No weakening of invariants.

Mutation Rules:
  Allowed:
    - Adding new perception primitives.
    - Extending feature extractors.
  Forbidden:
    - Allowing untyped perception.
    - Weakening meaning constraints.

Failure Modes:
  - Perception conflict → quarantine.
  - Invariant violation → reject.
  - Drift → rebuild.

Recovery Modes:
  - Rebuild perception graph.
  - Re-evaluate features.
  - Request new Vision Capsule.

Integration Rules:
  - Robotics organisms use vision-forge for perception.
  - BuddAI uses vision-forge for reasoning.
  - LEGION distributes perception tasks.

Affordances:
  - Perceive.
  - Validate.
  - Transform vision.

Boundaries:
  - Cannot override SCP.
  - Cannot self-author identity.

External Interfaces:
  - Cameras.
  - Sensors.

Summary:
  vision-forge provides typed, deterministic visual perception for the Forge organism.
