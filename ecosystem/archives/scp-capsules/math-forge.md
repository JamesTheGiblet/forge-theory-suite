SCP Capsule: math-forge
Semantic Identity:
  math-forge is the semantic mathematics organism. It defines the typed mathematical structures, operators, and invariants used across the Forge universe.

Purpose:
  To provide deterministic, meaning-preserving mathematical primitives for cognition, behaviour, robotics, intelligence, and semantic computation.

Core Behaviour:
  - Defines typed mathematical structures.
  - Validates mathematical invariants.
  - Provides operators for semantic computation.
  - Ensures deterministic mathematical reasoning.

Interpretation Rules:
  - All mathematical objects must be typed.
  - No contradictory axioms allowed.
  - No unbounded or ambiguous operations.
  - All transformations must preserve meaning.

Semantic Lineage:
  - Parent: forge_theory.
  - Sibling: logic-forge, data-forge.
  - Domain: Domain Forges.

Internal Invariants:
  - Mathematical structures must remain coherent.
  - No untyped transitions.
  - No circular definitions without fixed points.
  - No weakening of axioms.

Mutation Rules:
  Allowed:
    - Adding new operators.
    - Extending mathematical structures.
  Forbidden:
    - Contradicting forge_theory.
    - Allowing untyped mathematics.

Failure Modes:
  - Invariant violation → reject.
  - Contradiction → quarantine.
  - Divergence → halt.

Recovery Modes:
  - Rebuild structure.
  - Re-evaluate axioms.
  - Request new Math Capsule.

Integration Rules:
  - UBVM uses math-forge for computation.
  - BuddAI uses math-forge for reasoning.
  - LEGION uses math-forge for distributed consistency.

Affordances:
  - Define math.
  - Validate math.
  - Transform math.

Boundaries:
  - Cannot override forge_theory.
  - Cannot self-author identity.

External Interfaces:
  - Cognitive systems.
  - Behavioural systems.

Summary:
  math-forge provides the mathematical backbone for all semantic computation in the Forge organism.
