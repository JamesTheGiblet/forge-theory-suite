# Security Policy

## Supported Versions
Active development occurs in the main branch.  
Security updates apply to all maintained domains within the ecosystem.

## Reporting a Vulnerability
If you discover a security issue, please report it responsibly.

- Do not disclose vulnerabilities publicly.
- Provide a clear description, reproduction steps, and impact assessment.
- Include affected domain(s): Forge-Theory, Intelligence, Trading, UBVM, Robotics, or Utilities.

All reports will be reviewed promptly and addressed according to severity.
