# Quick Start Guide 🚀

Get up and running in 5 minutes!

## Step 1: Download

```bash
# Option A: Clone with Git
git clone https://github.com/JamesTheGiblet/BuddAI-lite.git
cd BuddAI-lite

# Option B: Download ZIP
# Click "Code" → "Download ZIP" on GitHub
# Extract to your desired location
```

## Step 2: Open in Browser

**Double-click `chatbot.html`**

That's it! No installation, no dependencies, no setup! 🎉

## Step 3: Test It Out

1. **Say hi**

```
   You: Hi!
   Bot: Hello lovely! 🌸
```

1. **Mention a project**

```
   You: I'm building a robot
   Bot: Ooh robotics! 🤖 [Creates project automatically]
```

1. **Switch modes**
   - Click the mode switcher (top right)
   - Try both Fluffy Bot 🐰 and Cool Boy 🤖

2. **Enable voice**
   - Click 🗣️ button
   - Bot will speak responses

## Step 4: Customize (Optional)

Edit `training-data.json` to add your own custom responses:

```json
{
  "customResponses": {
    "fluffy": {
      "my project name": ["Custom response! 🎀"]
    }
  }
}
```

Save and refresh - instant customization!

## Common Issues

**❌ Training data not loading?**

- Make sure both files are in the same folder
- Check browser console (F12) for errors

**❌ Voice not working?**

- Use Chrome or Edge for best support
- Check your browser's speech synthesis settings

**❌ Can't save preferences?**

- Don't use incognito/private mode
- Check if localStorage is enabled
