## 📖 Technical Documentation

### Architecture

```
chatbot/
├── index.html           # Single-file application
├── training-data.json   # Custom responses
└── [documentation]      # This folder
```

### Key Features

1. **Dual Personality System** - Fluffy Bot 🐰 & Cool Boy 🤖
2. **Learning System** - Tracks interests & adapts
3. **Project Management** - Auto-detection & tracking
4. **Voice Output** - Text-to-speech integration
5. **Export System** - 5 different formats

### Technologies

- **Frontend:** Vanilla JavaScript (ES6+)
- **Storage:** localStorage (browser-based)
- **Voice:** Web Speech API
- **No Dependencies** - Zero npm packages

## 🐛 Troubleshooting

### Common Issues

1. **Training data not loading** → Check browser console
2. **Voice not working** → Use Chrome/Edge
3. **Can't save preferences** → Don't use incognito mode
4. **LocalStorage errors** → Clear browser data
