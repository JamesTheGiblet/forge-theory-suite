# Contributing to Forge-Theory-Suite

Thank you for your interest in contributing to the Forge-Theory ecosystem.

## Principles
- Semantic clarity over complexity  
- Minimal dependencies  
- Deterministic behaviour  
- No global mutable state  
- No ambiguous interfaces  
- No unsafe behaviours (robotics)  
- No unbounded growth (simulation)

## How to Contribute
1. Fork the repository.
2. Create a feature branch.
3. Ensure your contribution aligns with the suite’s invariants.
4. Submit a pull request with a clear description.
